# KB Project Agent

## Context

This workspace contains:
- **kb-cli/**: Node.js CLI tool for programming the Hanlinyue Free2 macro keyboard via USB serial
- **hanlinyue.app/**: The vendor's Electron app (reference for protocol reverse-engineering)

## Key Reference

Protocol details, wire format, segmentation, transport, and serialport write behavior are documented in [hanlinyue-free2-protocol.md](hanlinyue-free2-protocol.md).
